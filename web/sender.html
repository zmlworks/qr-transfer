送り方 / how codes advance
プロトコル QT1: QT1:ID:INDEX:TOTAL:CRC32:BASE45 — 英数字モードQRで送ります。CRC32は元データ全体のもの。 2枚表示: 左(上)=偶数番、右(下)=奇数番。確認音 (v0.3.0〜、交互ビット): 受信側 (0.3.0 以降) は読んだチャンクごとに、 左(上)なら 1350 / 1700 Hz、右(下)なら 2050 / 2400 Hz を 1枚ごとに交互に鳴らし (A0/A1/B0/B1)、完了で 3050 Hz を長めに鳴らします。 マイク確認モード (既定) では、表示中のチャンクちょうどの確認音を聞いたコードだけが次へ進みます (タイムアウトで飛ばすことはありません。 古い確認音は無視)。マイクが使えなくても自動送りには切り替わりません — 自動送り (ループ) は上の選択か「ループに切替」ボタンでだけ選べます。 送信前に「🎤 マイク診断」で受信アプリの「テスト音」が聞こえるか確かめてください。 / Mic-ack mode (default): a code advances only on the ack for exactly the chunk it shows (no timeouts, stale acks ignored). It never falls back to auto-advance by itself; loop is only chosen by you.
